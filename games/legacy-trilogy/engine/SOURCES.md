The browser runtime is EmulatorJS 4.2.3 from the @emulatorjs/emulatorjs npm package. The bundled single-threaded mGBA cores are from @emulatorjs/core-mgba 4.2.3. Game cartridges are imported locally by the player.

- https://github.com/EmulatorJS/mgba
- https://www.npmjs.com/package/@emulatorjs/core-mgba/v/4.2.3
